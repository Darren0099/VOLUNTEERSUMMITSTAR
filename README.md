# Volunteer Summit of Stars — Interview Schedule Page

Halaman informasi **jadwal wawancara rekrutmen volunteer tahun 2025**, dirancang agar panitia dan peserta lebih mudah menelusuri jadwal berdasarkan hari serta mengenali petugas wawancara.

## Fitur yang dibuat

- **Daftar pewawancara** dalam susunan kartu.
- **Kelompok jadwal per hari** dengan bagian yang dapat dibuka dan ditutup.
- Tampilan informasi wawancara dan pembagian slot secara terstruktur.
- Layout adaptif untuk layar desktop maupun ponsel.

## Teknologi

**HTML**, **CSS**, dan **JavaScript** dalam satu file `index.html`, dengan tipografi **Poppins**.

## Hasil dan batasan

Proyek menghasilkan **halaman referensi jadwal**, bukan sistem booking slot atau manajemen kehadiran yang terhubung ke database. Perubahan jadwal pada versi ini dilakukan melalui sumber halaman. Nama dan jadwal yang tercantum merupakan arsip kegiatan; verifikasi ulang diperlukan sebelum digunakan untuk agenda baru.
